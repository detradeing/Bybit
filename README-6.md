# Auto-Trader (Bybit Demo + GitHub Actions + Telegram)

## نکات مهم قبل از اجرا
1. `demo=True` در `bybit_client.py` فقط برای **حساب دمو بای‌بیت** است. API Key/Secret باید مخصوص دمو باشند
   (از داشبورد Demo Trading بای‌بیت ساخته شوند)، نه کلید حساب واقعی.
2. اولین اجرا باید فایل‌های خالی `state.json` (`{"open_position": null}`) و `price_history.json` (`[]`)
   را در ریشه ریپازیتوری داشته باشد تا Actions بتواند آن‌ها را کامیت کند.
3. دقت qty فعلاً به صورت ساده رند شده (`round(qty, 3)`). قبل از اجرای واقعی پیشنهاد می‌شود
   `qty` طبق `instruments-info` نماد (lotSizeFilter) گرد شود تا خطای سفارش نگیرید — اگر بخوای این بخش رو هم اضافه می‌کنم.
4. TP/SL به‌صورت native روی خود صرافی (`takeProfit`/`stopLoss` در سفارش) تنظیم می‌شود؛ یعنی حتی اگر
   Actions بین دو اجرا مشکلی داشته باشد، بسته شدن معامله وابسته به اجرای بعدی بات نیست — فقط ارسال گزارش
   به اجرای بعدی بستگی دارد.
5. منطق فعلاً فقط **Long** است؛ افزودن Short بعداً به همین ساختار قابل اضافه شدن است.
6. **باگ مهمی که رفع شد:** اندپوینت `get_closed_pnl` بای‌بیت روی حساب دمو اصلاً پشتیبانی نمی‌شود
   (خطای رسمی `ErrCode 10032`). به همین دلیل گزارش تلگرام دیگر به آن متکی نیست؛ به‌جایش قیمت خروج از
   `get_executions` و سود/ضرر خالص از **اختلاف موجودی کیف‌پول قبل و بعد از معامله** محاسبه می‌شود که
   روی حساب دمو کار می‌کند.
7. **مورد نامطمئن:** `switch_margin_mode` که برای Isolated فراخوانی می‌شود، مربوط به حساب‌های Classic بای‌بیته؛
   در حساب‌های UTA (که دمو هم روی همون ساختاره) ممکنه این مقدار عملاً از تنظیمات کلی حساب (نه هر نماد) خونده بشه
   و این فراخوانی بی‌اثر باشه. برای اطمینان، حالت Isolated رو یک‌بار دستی هم از داخل اپ/سایت بای‌بیت برای BTCUSDT تنظیم کن؛
   کد در `try/except` پیچیده شده پس اگر ناموفق باشه خطایی باعث توقف بات نمی‌شه، فقط بی‌اثره.
8. به ورک‌فلو `concurrency` اضافه شد تا اگر یک اجرا دیرتر از ۵ دقیقه طول بکشه، اجرای بعدی هم‌زمان روی
   `state.json` رقابت (race condition) نکنه.

## اجرای محلی برای تست
```bash
pip install -r requirements.txt
export BYBIT_API_KEY=...
export BYBIT_API_SECRET=...
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID=...
python main.py
```
